# RX 7900 XTX (RDNA3, gfx1100) — target card

Not yet purchased (as of 2026-10-25). Target one used card at €800–900; a second
only if wanted later. Destined for the benchmark-host host, replacing the 6700 XT.

- **Silicon:** Navi 31, gfx1100, RDNA3. 96 CUs, ~123 TFLOPS FP16 (same as W7900;
  only the power cap differs).
- **Memory:** 24 GB GDDR6, 384-bit, ~960 GB/s — ~2.5× the 6700 XT's ~384 GB/s.
- **Why it matters here:** 24 GB fits the production Qwen3.6-35B-A3B IQ4_XS
  (~18–20 GB) entirely in VRAM, so `--n-cpu-moe 0` removes the CPU-expert offload
  that caps decode today — the main expected win, at full quality.
- **Open hardware questions** (see [open-questions.md](open-questions.md)): PSU
  rating (≥800 W), case clearance (2.5–3.5-slot, up to ~340 mm), and the Linux
  power cap (reportedly defaults to 291 W rather than 355 W).
- **Software:** ROCm/HIP and Vulkan/RADV both target gfx1100; which wins is
  unsettled and gets its own A/B on arrival.
